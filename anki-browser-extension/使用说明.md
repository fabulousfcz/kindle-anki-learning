# 生词一键进 Anki —— Edge 扩展使用说明

这个扩展让你在 Edge 浏览器里读英文文章时，**选中单词 → 一键加进电脑 Anki**，
和 Kindle 选词共用同一个牌组「英语生词本」和笔记类型「英语词汇-词根词源」。
词根词缀、词源由你电脑上的监听器自动补全。

---

## 一、安装扩展（一次性，约 1 分钟）

1. 打开 Edge，在地址栏输入并回车：
   ```
   edge://extensions/
   ```

2. 打开页面**左下角**的「**开发人员模式**」开关（Developer mode）。

3. 点击左上角「**加载解压缩的扩展**」（Load unpacked）。

4. 在弹出的文件夹选择窗口里，选中这个文件夹：
   ```
   C:\Users\Cysteine\WorkBuddy\2026-10-08-05-36-38\anki-browser-extension
   ```
   （就是包含 manifest.json 的那个文件夹，选整个文件夹，不要选里面的文件）

5. 看到扩展「**生词一键进 Anki**」出现在列表里，就成功了。

> 💡 建议：点浏览器右上角的「拼图」图标，把这个扩展**固定**到工具栏，方便看到它的状态。

---

## 二、使用（装好后，每天就是这么用）

### 前提
电脑上的 **Anki 必须正在运行**（这是和 Kindle 同步的同一个前提）。

### 操作方式（任选其一）

**方式 A：划词浮动按钮（最快）**
1. 在网页上**用鼠标选中一个英文单词**（双击单词即可选中）；
2. 单词旁边会浮出一个绿色的「**+Anki**」小按钮；
3. 点它，单词就进 Anki 了。

**方式 B：右键菜单**
1. 选中英文单词；
2. **右键** → 点「**把这个词加进 Anki**」。

### 成功提示
- 加词成功：页面顶部弹绿色提示「✓ 已加入 Anki」；
- 这个词已经学过：弹橙色提示「⚠ 已在 Anki 里」（不会重复添加）。

### 加进去之后
- 卡片进入「英语生词本」牌组，正面是「单词」，背面空着；
- 你的监听器会在几秒内自动补上「音标 / 释义 / 例句 / 词根词缀 / 词源」。

---

## 三、设置（一般不用改）

点击扩展图标，会弹出设置面板，可以改：
- **牌组名**：默认「英语生词本」
- **笔记类型名**：默认「英语词汇-词根词源」
- **单词字段名**：默认「单词」

改完点「保存设置」。面板打开时还会自动检测 Anki 是否在线。

> 这些默认值已经和你的 Anki 完全匹配，**正常情况下不需要动**。

---

## 四、常见问题

| 问题 | 解决 |
|---|---|
| 点了没反应 / 提示连接失败 | 确认电脑上的 Anki 已启动、AnkiConnect 已加载 |
| 词加进了别的牌组 | 点扩展图标，检查牌组名是否还是「英语生词本」 |
| 想删掉某个词 | Anki 里按 `B` 打开浏览 → 选中词 → `Ctrl+Delete` |
| 想卸载扩展 | edge://extensions 里找到它 → 移除 |
